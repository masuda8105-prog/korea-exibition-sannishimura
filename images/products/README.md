# Product images

Put product images here.

Recommended naming:

- `1053.jpg`
- `1054.jpg`
- `0756-01.jpg`
- `141-503.jpg`

The app automatically tries `images/products/<品番>.jpg` when the CSV has no image column.

You can also add either of these columns to the CSV:

- `画像ファイル名` 例: `1053.jpg`
- `画像URL` 例: `https://example.com/1053.jpg`
