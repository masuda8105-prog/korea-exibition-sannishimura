# サンニシムラ 韓国展示会 注文ツール（UI修正版）

韓国展示会でスタッフ・お客様のどちらでも直感的に使えるよう、スマホ優先で設計した静的Webアプリです。

## 操作画面

- 検索欄はPC・スマホとも画面上部に固定
- 検索結果は固定検索欄の下から始まり、重ならないよう高さを自動調整
- スマホでは端末標準の通常キーボードを使用
- 数字・英字・商品名・キーワードを同じ検索欄から入力可能
- 専用テンキー、数字／ABC切替ボタンは廃止
- 商品カードに「詳細・HP」ボタンを表示
- 詳細画面で商品画像、品番、価格、用途、仕様、カタログ情報、公式HPを確認可能
- 画面下部の注文カートは常時表示
- 「カート内容を確認」から数量変更・削除画面を開く
- QR発行ボタンを押すと、お客様情報入力画面が開く
- 独立した「お客様情報」ボタンは廃止
- 合計金額は注文カート内だけに表示

## 注文・控えの仕様

- 表示言語：日本語 / 한국어
- 価格：韓国ウォン（KRW）固定
- 商品数：3,831件
- 会社名・氏名・電話番号は必須
- QRは品番・数量を中心に軽量化
- 控えにはサンニシムラロゴとKY-S Corporation.情報を表示
- 控えの「入数」列は非表示
- 商品画像を控えへ表示
- A4印刷用レイアウト対応

## 価格データ

- 元データの余分な0を1つ取り除き、価格を10分の1に修正済み
- 100ウォン単位で四捨五入
  - 4,347ウォン → 4,300ウォン
  - 4,350ウォン → 4,400ウォン

## 設置方法

Webサーバー、GitHub Pages、または現在使用中の公開環境へ、フォルダー内のファイルをそのまま配置してください。

```text
index.html
product_master_korea.csv
product-images/
assets/
vendor/
```

## 名刺写真機能
- お客様情報入力画面の「名刺を撮影・選択 / 명함 촬영·선택」から、スマートフォンのカメラまたは保存画像を選択できます。
- 選択した画像は自動的に縮小・JPEG圧縮され、撮影した端末の仮注文書控えに表示されます。
- 名刺画像はQRコードには含まれません。QR容量を圧迫せず、スタッフ確認用QRを軽量に保ちます。
- 名刺画像はブラウザのセッション内で注文番号と紐づけて保持します。同じ端末でスタッフ確認後に控えを開き、印刷／PDF保存してください。
- 注文履歴には名刺画像を保存しません。

## オンライン名刺共有版

名刺画像を高画質のまま別端末へ共有するためのSupabase対応ファイルを追加しています。
設定手順は `オンライン名刺共有_SETUP.md` を確認してください。

設定前は従来どおりローカル動作しますが、名刺写真は別端末へ共有されません。
